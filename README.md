# Article I Found Interesting
[Enjoyable Game Architecture](https://chickensoft.games/blog/game-architecture)
# Why I Found It Interesting

What I find interesting about the article is its emphasis on architecture as a way to manage complexity, rather than simply as a collection of design patterns. As a designer, we tend to focus on quickly testing and evaluating playability. However, games can accumulate complexity very quickly, which can often lead to spaghetti code. Since games typically go through frequent and sometimes significant iterations, architecture becomes especially important. A well-designed structure can make it much easier to change, test, and iterate on different parts of a game without creating unnecessary complications.

The approach also seems to treat game development as an iterative process, where the architecture needs to support experimentation rather than fight against it. That’s an important distinction from more rigid software architectures. In games, mechanics and systems often need to be changed repeatedly as you discover what is actually fun. Having a structure that keeps those changes localized can make a big difference in both the development process and the ability to experiment with new ideas.
